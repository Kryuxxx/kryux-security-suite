# Security Policy

## Authorized use only

The KRYUX Security Suite is a **defensive security and audit workbench** for:

- your own systems and home lab,
- customer systems **only with prior written authorization**,
- learning platforms such as TryHackMe / HackTheBox (your own lab machines).

Active modules (Nmap, Nikto, SQLMap, Metasploit runner) must only target
in-scope systems. The engagement module (`Einsatz & Report`) documents scope
and findings for professional use.

## Reporting a vulnerability

If you find a security issue **in the suite itself**, please do **not** open a
public issue. Use **GitHub → Security → Report a vulnerability** (private
Security Advisory). We aim to acknowledge reports within 7 days.
